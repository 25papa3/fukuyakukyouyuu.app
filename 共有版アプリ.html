使う人を選んでください

共有するのは、お子さん1人分の記録だけです。入力するのはお子さん、見るのは両親、と役割が分かれています。

両親自身の起床・食事・服薬・就寝は、この共有版ではなく、今まで使っている各自のアプリでこれまでどおり入力できます。この共有版で共有されるのは、お子さんの分だけです。

共有のしくみ

  • 入力お子さんがタップすると、記録が共有先（家族のスプレッドシート）へ送られます
  • 閲覧両親の画面は開くたびに最新を読み込み、開いている間も1分ごとに自動で更新されます
  • 範囲共有されるのはお子さんの記録だけ。他の家族の記録は今までどおり各端末の中だけです
  • 保護合言葉を知っている家族の端末からだけ読み書きできます

      かんたん設置ガイド（最初に1回だけ・Googleアカウント側の作業）
      1. パソコンでGoogleスプレッドシートを新規作成します（名前は「服薬記録」など何でもOKです）。
      2. メニューの「拡張機能」→「Apps Script」を開き、最初から入っている文字を全部消して、下のプログラムを貼り付けます。1行目の ここに合言葉を設定 の部分を、家族で決めた合言葉に書き換えて保存します。
      3. 右上の「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」を選び、「アクセスできるユーザー」を「全員」にしてデプロイします。表示されたURL（…/exec で終わるもの）をコピーします。
      4. このページの「共有の接続設定」に、そのURLと合言葉を入れて「接続して読み込む」を押します。お子さんの端末・両親の端末それぞれで、同じURLと合言葉を設定してください。
      5. お子さんが記録するとスプレッドシートに行が増え、両親の画面には開くたび＋1分ごとに自動で反映されます。

const SHEET_NAME = 'records';

function getSheet_() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sh = ss.getSheetByName(SHEET_NAME);
  if (!sh) {
    sh = ss.insertSheet(SHEET_NAME);
    sh.appendRow(['id', 'type', 'ts']);
  }
  return sh;
}
function checkPass_(p) {
  if (p !== PASS) throw new Error('合言葉が違います');
}
function out_(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
function doPost(e) {
  try {
    const b = JSON.parse(e.postData.contents);
    checkPass_(b.pass);
    const sh = getSheet_();
    if (b.action === 'list') {
      const rows = sh.getDataRange().getValues();
      const records = [];
      for (let i = 1; i < rows.length; i++) {
        if (rows[i][0]) {
          records.push({ id: String(rows[i][0]), type: String(rows[i][1]), ts: String(rows[i][2]) });
        }
      }
      return out_({ ok: true, records: records });
    }
    if (b.action === 'add') {
      sh.appendRow([b.id, b.type, b.ts]);
    } else if (b.action === 'delete' || b.action === 'update') {
      const rows = sh.getDataRange().getValues();
      for (let i = 1; i < rows.length; i++) {
        if (String(rows[i][0]) === String(b.id)) {
          if (b.action === 'delete') sh.deleteRow(i + 1);
          else sh.getRange(i + 1, 3).setValue(b.ts);
          break;
        }
      }
    }
    return out_({ ok: true });
  } catch (err) {
    return out_({ ok: false, error: String(err.message || err) });
  }
}
